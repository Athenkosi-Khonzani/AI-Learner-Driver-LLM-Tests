# Phase 1 - Simulator Design

## Purpose

Phase 1 validates the benchmark environment before any LLM APIs are introduced.

The benchmark project is intentionally independent from `ai_learner_host`.

## Coordinate frame

- Origin: arena bottom-left
- +X: right
- +Y: up
- Heading 0°: +Y
- Heading 90°: +X
- Positive TURN: right/clockwise
- Negative TURN: left/anticlockwise

## LLM-facing plan schema

```json
{
  "cmds": [
    {"op": "TURN", "value": -30},
    {"op": "FWD", "value": 200},
    {"op": "STOP", "value": null}
  ]
}
```

## Deterministic wire compilation

The host-facing wire representation is generated by code:

```json
[
  ["TURN", -30],
  ["FWD", 200],
  ["STOP"]
]
```

## Safety simulation

The simulator checks the full rover rectangle against:
- rotated rectangular obstacles,
- arena boundaries.

Translation is sampled every 5 mm.
Rotation is sampled every 1 degree.

## Objective evaluation

The hidden goal is not included in the LLM world state.

Metrics remain separate:
- task success,
- collision,
- boundary violation,
- final position error,
- final heading error,
- travel distance,
- total rotation,
- command count.
